# Case strength

## The ten categories

Every successful run scores the matter out of 100 in ten categories.

| Category | |
| --- | --- |
| **Overall strength** | The headline figure. |
| Liability | Damages |
| Evidence | Witness credibility |
| Defendant exposure | Settlement leverage |
| Trial readiness | Procedural risk |
| Case completion | |

A category the run could not price shows as *not scored*.

## Movement

A score that changed since the previous version shows its previous value and, on
expansion, **why it moved** — in prose, tied to the developments that caused it.

A score seen for the first time is marked **New**; one that did not move is
marked **No change**.

**Score history** draws the trend across versions for whichever category you
pick, with each point labelled by version and the phase the matter was in.

<Callout type="info">
  A matter getting weaker is shown as plainly as one getting stronger. That is
  the point of keeping every version.
</Callout>

## Overriding a score

An attorney can override any score with a value and a **required reason**.

The override is what the product then shows, marked **Overridden**, with a note
recording who set it, to what, and what the engine had scored. **Remove
override** hands the category back to the engine.

An override does not silence the engine. Later runs still score the category;
you keep seeing what it thinks alongside what you decided.

## On the dashboard

**Portfolio strength** splits every analysed matter into four bands — Strong
(80+), Good (60–79), Moderate (40–59), Weak (under 40) — plus the matters not
yet analysed, and gives the firm-wide average.

**Score movement** lists the matters whose overall strength moved most recently,
with the version and when.

Both are scoped to the matters you are on.

## Where the numbers do not appear

The run review screen carries no model, token or cost figure. Spend is tracked
for the firm's own books and is not shown on a matter.
