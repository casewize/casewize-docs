# Gaps, contradictions, actions

## Evidence gaps

What the analysis knows to ask for and cannot find on the file. Each gap says
**how to get it**.

Ten categories: missing document · missing testimony · missing damages support ·
missing causation evidence · missing policy or procedure · missing
communications · missing expert analysis · missing authentication · incomplete
discovery response · unresolved contradiction.

States: **Open**, **In progress**, **Resolved**, **Unavailable**, **No longer
relevant**.

A gap answered by a document that arrives later closes on its own, and the
product tells you which document did it — *Answered by Maintenance log
2019–2021*. Closed gaps are hidden by default; **Show closed** brings them back.

*No open gaps* means everything the analysis knows to ask for is on the file.

## Contradictions and corroboration

Two lists, from the same pass over the record.

**Contradictions** — where the record disagrees with itself. Each shows both
sides: *the record says* against *against*.

Types: inconsistent dates · conflicting statements · testimony against a
document · account changed.

**Corroboration** — where it agrees. Confirmed by witnesses · document
corroborates testimony. And the inverse, flagged as an *unsupported allegation*.

Each carries a state you set: **Open**, **Resolved**, **Explained**, **Still
disputed**.

## Recommended actions

What the analysis thinks should happen next, most urgent first, each with its
**expected impact**.

Twelve categories: discovery request · deposition question · witness follow-up ·
document request · expert consultation · motion strategy · settlement
preparation · damages development · credibility investigation · evidence
preservation · trial preparation · client follow-up.

Priority: critical, high, moderate, low.

### Turning one into a task

**Make a task** puts it on the matter's task board, optionally assigned to
someone. The action then shows *on the board, assigned to …*.

Marking an action **complete** is one of the triggers that starts a fresh
analysis run — the point being that the run then re-reads the file with the
thing you did on it.

States: Open · In progress · Completed · Dismissed · Superseded.

## Evidence impact

A map of what supports what. Each link joins a piece of evidence to a target,
with a relation and a strength out of 100.

**Targets:** claim · defense · element · witness · damages · issue · score.

**Relations:** supports · contradicts · corroborates · impeaches · authenticates
· quantifies.

**Kinds of evidence:** direct · circumstantial · testimonial · documentary ·
expert · demonstrative.
